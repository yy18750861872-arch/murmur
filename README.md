# Murmur

面向 iPhone 的场景声音收藏与放松工具。当前为静态网页 MVP，无需构建依赖。

## 运行

在项目目录执行 `python -m http.server 8080 --directory dist`，打开 http://localhost:8080 。线上 HTTPS 地址可从 Safari 添加到主屏幕。

## 已实现

- 首页、场景筛选、声音库搜索、我的页面
- HTTP/HTTPS 链接收藏、去重、删除、浏览器本地保存、JSON 导出
- 三种本地合成噪音，播放暂停、音量、定时结束前渐弱
- 常驻迷你播放条与完整播放弹窗
- 外部收藏明确跳转，不伪装跨 App 控制

## 边界

这不是原生 iOS App。无 AI、云同步、跨 App 控制或系统分享扩展。收藏仅存于当前浏览器。音频由 Web Audio 本地合成，无外部音频素材。Safari 锁屏、后台播放与后台定时需要 iPhone 真机验证，不能保证。未收集真实用户研究数据，也不声称改善睡眠。

## 产品假设与验证

假设：按使用场景整理跨平台链接，可缩短找回已收藏声音的时间。计划让真实参与者分别从原平台和 Murmur 找到指定收藏，平衡任务顺序，记录耗时、成功率、点击次数、便利性评分。结果尚待测试。
